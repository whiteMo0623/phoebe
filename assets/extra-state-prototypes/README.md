# Extra state prototypes

These transparent PNG strips are storyboard prototypes for states that are not
part of the fixed Codex v2 atlas row contract:

- `success.png` — Success / Build Passed
- `sleeping.png` — Sleeping / Zzz
- `loading.png` — Loading / processing core

Each strip contains six left-to-right poses. The installable
`../spritesheet.webp` keeps the standard Codex v2 rows and remains the only
runtime-ready asset. These strips are intended for future animation-layer
work, previews, stickers, or further frame assembly.
