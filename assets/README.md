# Runtime assets

The smallest installable package is:

- [`pet.json`](pet.json)
- [`spritesheet.webp`](spritesheet.webp)

The PNG atlas is kept as an inspection/editing fallback. GIFs and contact
sheets are previews only; they are not Codex runtime inputs.

The `extra-state-prototypes/` directory contains transparent storyboard strips
for Success, Sleeping, and Loading. They are intentionally separate from the
fixed Codex v2 atlas.
